Portabilité · Conteneurisation · Déploiement

Un site statique, empaqueté une fois, déployable partout.

Cette landing page HTML / CSS / JavaScript, sans aucun framework, est servie par Nginx à l'intérieur d'une image Docker légère. Le même artefact tourne à l'identique sur votre poste, en CI et en production.

Ce que démontre ce projet

Un exemple concret et minimal des bonnes pratiques de conteneurisation d'un site statique, prêt pour la production.

  • 🚀

    Portabilité totale

    Une seule image embarque le serveur et les fichiers. Aucun « ça marche sur ma machine » : l'artefact est identique partout.

  • 🛡️

    En-têtes de sécurité

    CSP, X-Content-Type-Options, Referrer-Policy et compagnie sont appliqués directement par Nginx pour durcir la diffusion.

  • ⚡

    Performances

    Compression gzip et stratégie de cache HTTP réglées pour servir les ressources statiques rapidement et efficacement.

  • 🔒

    Moindre privilège

    Le conteneur s'exécute sous un utilisateur non-root, avec un HEALTHCHECK intégré pour la supervision de l'état du service.

  • 🔁

    CI/CD automatisée

    Un workflow GitHub Actions construit l'image et la publie sur le GitHub Container Registry (GHCR) à chaque push sur main.

  • 📱

    Responsive & sobre

    Une interface épurée, accessible et adaptée à tous les écrans, écrite en HTML/CSS/JS pur, sans dépendance externe.

Stack technique

Des briques standard, éprouvées et volontairement minimalistes.

Nginx (Alpine)

Serveur web ultra-léger qui diffuse les fichiers statiques et applique compression, cache et en-têtes de sécurité.

Docker

Empaquetage de l'application et de son serveur dans une image immuable et reproductible.

Docker Compose

Orchestration locale du service web avec la projection de port 8088:80 pour un démarrage en une commande.

GitHub Actions + GHCR

Construction et publication continues de l'image sur le registre de conteneurs de GitHub.

Démarrage rapide

Construisez l'image et lancez le conteneur, puis ouvrez le site en local.

terminal 
# Construire l'image
docker build -t docker-static-site .

# Lancer le conteneur
docker run --rm -p 8088:80 docker-static-site

# Ou tout en un avec Docker Compose
docker compose up --build

Une fois le conteneur démarré, ouvrez http://localhost:8088.
